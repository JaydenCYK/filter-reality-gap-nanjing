# Filter-Reality Gap in Tourism Social Media — Reproducibility Code

Reproducibility package for:

> *The Filter-Reality Gap in Tourism Social Media: Content Analysis of Image
> Misalignment and Destination Trust Erosion — Evidence from Nanjing, China*

This repository contains the open-source scripts and pre-computed aggregate
statistics that reproduce **every number published in the manuscript** (Tables
1–3, the N = 498 / 176 / 235 / 87 sentiment baseline, the four-dimension gap
counts 9 / 24 / 26 / 12, and the platform × dimension cross-tabulation).

It is intentionally self-contained: standard library only, no data
dependencies, runs on any Python 3.8+ installation.

---

## What is (and is not) in this repository

| Included | Not included |
|---|---|
| `clean_and_analyze.py` — cleaning + two-level sentiment + element frequencies (N = 498) | The raw UGC text |
| `invivo_stats.py` — in-vivo code counts, dimension unions, platform × dimension cross-tab | Identifying metadata (usernames, IP, geo) |
| `element_sentiment.py` — per-element positive / neutral / negative distribution (Table 1) | |
| `verify.py` — one-command check that every published number is reproduced | |
| `expected_outputs/*.json` — the exact aggregate values published in the paper | |
| `sample_corpus/` — a small de-identified sample (a handful of records, identifying fields removed) illustrating the input format | |

**Why the raw corpus is not public.** The source records were collected from
Ctrip and Xiaohongshu, whose terms of service restrict redistribution of
user-generated content. We therefore do **not** publish the raw UGC here.
All *aggregate* statistics (which are the numbers actually reported in the
paper) are fully reproducible from the scripts above, and a de-identified copy
of the raw corpus is available from the corresponding author on reasonable
request. No personally identifying information appears anywhere in this
repository.

## Quick start

1. **Get the corpus.** Place the full raw corpus at `corpus/_user_reviews.txt`
   (one UGC record per line; the de-identified copy is available from the
   corresponding author on reasonable request). For a smoke test of the
   pipeline only, point the scripts at `sample_corpus/sample_records.txt`.

2. **Run the one-command check.** From the repository root:

   ```bash
   python scripts/verify.py
   ```

   This runs all three analysis scripts against the corpus and compares the
   freshly generated `outputs/*.json` against the published benchmarks in
   `expected_outputs/`. A `ALL CHECKS PASSED` result means every figure in the
   manuscript is reproduced exactly.

   To point at a non-default corpus location:

   ```bash
   UGC_CORPUS=/path/to/_user_reviews.txt python scripts/verify.py
   ```

3. **Run individual scripts** (each writes into `outputs/`):

   ```bash
   python scripts/clean_and_analyze.py    # -> outputs/ugc_stats.json
   python scripts/invivo_stats.py         # -> outputs/invivo_stats.json
   python scripts/element_sentiment.py    # -> outputs/element_sentiment.json
   ```

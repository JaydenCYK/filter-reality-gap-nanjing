# Raw corpus location
The full raw UGC corpus (one record per line, ~962 lines) is intentionally NOT
committed to this repository, in line with the source platforms' terms of
service (Ctrip and Xiaohongshu restrict redistribution of user-generated
content).

To run the analysis scripts locally you need the raw corpus at:

    corpus/_user_reviews.txt

A de-identified copy is available from the corresponding author on reasonable
request. Only the files described in the repository root `README.md` are
required to reproduce the published aggregate statistics; the raw text is
never redistributed here.

This folder is otherwise ignored by git (see `.gitignore`).
